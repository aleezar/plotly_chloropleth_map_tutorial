# Plotly Chloropleth Map Tutorial
Interactive Choropleth Map Tutorial: Visualizing the Global Hunger Index

# Overview
This project was developed as part of a CMSE 402 Honors Option and draws upon concepts from course readings and discussions.

This repository contains a jupyter notebook titled CMSE402_plotly_chloropleth_map.ipynb, which is a step-by-step tutorial that demonstrates how to create an interactive choropleth map using Plotly Express. The tutorial walks users through the process of building a map that visualizes the Global Hunger Index (GHI) by country and year.

The dataset used can be found at: https://www.kaggle.com/code/sasakitetsuya/global-hunger-index-analysis/input
